# Café Origen - Motor de Analítica v0.1

## Descripción

Café Origen es un proyecto desarrollado en JavaScript para analizar las ventas de una tienda de café. Permite organizar la información y generar reportes para conocer el comportamiento de las ventas.

## Cómo ejecutar el proyecto

1. Tener instalado Node.js.
2. Abrir la terminal en la carpeta principal del proyecto.
3. Ejecutar el siguiente comando:

```bash
node src/reporte.js
```

El programa muestra un reporte en consola con el resumen general, las ventas por ciudad, las unidades por producto y los tres productos con mayor valor generado.

## Preguntas que responde

- ¿Cuánto dinero se ha vendido en total?
- ¿Cuántas unidades se han vendido?
- ¿Cuál es el ticket promedio?
- ¿Cuánto se ha vendido en cada ciudad?
- ¿Cuántas unidades se han vendido por producto?
- ¿Cuáles son los tres productos que generan más dinero?
- ¿Cuánto se vendió en una fecha específica?
- ¿Qué resultados se obtienen cuando un día no tiene ventas?
